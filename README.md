# Lorebound downloads

A Windows worldbuilding companion for tabletop campaigns: organize your wiki,
keep a personal journal, create a custom calendar, and generate names.

**[Download the Windows beta](https://github.com/runeparadox/Lorebound-downloads/releases)**

Choose **Lorebound-Setup.exe** for normal installation. No Python installation
is required. For an extracted-folder version, download **Lorebound-Windows.zip**,
extract the entire archive, and run **Lorebound.exe** inside the Lorebound folder.

Requires 64-bit Windows 10 or 11. Read the release notes for beta limitations.
The beta is unsigned. **SHA256SUMS.txt** lists download checksums.

Use **Help → Check for updates** inside Lorebound, or watch this repository's
releases on GitHub. Close Lorebound before installing an update. Projects and
personal notes stay in your Windows account's `%LOCALAPPDATA%\Lorebound` folder;
updating or uninstalling the program does not remove them. Back up important work.

This repository distributes installers and release information only. The
application source repository is private. GitHub's automatic “Source code” ZIP
and TAR downloads contain this download page's files, not Lorebound's source.
